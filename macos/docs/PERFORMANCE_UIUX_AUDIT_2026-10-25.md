# パフォーマンス・UI/UX 再監査 — 2026-10-25

## 対象と方法

- `origin/main` の `64908b4` を基点に監査。開始時の作業ツリーはクリーン。
- macOS 27.0.1 / Apple Silicon / Swift 6.4。インストール済み0.3.1の画面で現象を確認し、修正版は別IDの検証アプリで操作した。
- ホーム、フォルダ設定、セット検索、プラグイン一覧、サンプル一覧を実画面で確認。コード監査と再現テストで、画面だけでは判断できないキャンセル・キャッシュ・非同期処理を検証した。
- 検証アプリは専用 `ALIVE_HOME` と合成24セット・8音声を使用。Spotlight・メニューバー・Finderタグ連携は無効。
- Dropboxの同期と実ライブラリの再スキャンは、ユーザーの指示で対象外とした。

## 修正

| 問題・影響 | 修正と確認方法 |
|---|---|
| フォルダを変更せず「スキャン」を押すと、設定画面が閉じるだけで再試行されない | 表示中のページを再スキャン。実画面でスキャン表示と新しい完了ログを確認。合成セットの更新を同じパスで再読込する回帰テストも追加 |
| サンプルフォルダ変更時、設定更新による自動スキャンと明示スキャンが重なる | 両ページの設定を1回で保存し、サンプルは既存の自動開始に一本化。設定画面の件数計算も送信時に停止 |
| 無効化済みのプロジェクトフォルダを再選択しても、有効化が保存されない | 重複登録せず再有効化を保存し、スキャンを開始。保存内容と実際の読込結果を回帰テストで確認 |
| 内部カタログの世代だけが変わると、プラグインの古い行や移動先が残る | 行キャッシュを世代と値型の検索条件で識別。新しいプラグインへの移動要求は最新一覧の完成まで保持。修正前に失敗した2件を含むモデルテストで検証 |
| 未ハッシュ音声が多いと、重複判定がキャンセルを確認しない | ハッシュ値による除外より前にキャンセルを確認。未ハッシュ位置に依存せず停止する回帰テスト |
| サンプルのフォルダツリー作成にキャンセル確認がない | 開始時・フォルダごと・256ファイルごとに確認。中断時は途中の行を返さない。8,192ファイルの合成ケースで確認 |
| AIFFを同じサイズで置換すると、古い再生可否が再利用される | サイズに加えて更新日時を比較。変更時はヘッダを再確認し、日時を持たない旧v2キャッシュの互換動作は維持 |
| クラウドフォルダがMacから外れている場合にも「移動または削除」とだけ案内する | Macでフォルダを表示できる状態にしてから再スキャンする手順を日英で案内。行ごとの復旧ボタンには対象パスのアクセシビリティラベルを追加 |
| 全ルートが見つからない場合、旧カタログを保持している説明が省略される | 旧カタログ保持時は、フォルダ不在の行と併せて最新の状態とは異なる旨を必ず表示 |
| 読込処理より先に所有モデルが解放されると、完了通知が解放済み参照を読む | 起動・スキャン・ドライブ変更の非同期処理と進捗通知の間は所有モデルを保持。セマフォで処理を止めて外部参照を解放する4件のテストで、安全な完了と完了後の解放を確認 |
| 保存済み一覧を保持したままルートが消えると、存在しないセットが「今すぐ開ける」に残る | 確認済みの消失ルート配下に限り、表示時の状態を読込不可へ補正。追加ディスクアクセスなしでHomeの件数とSetsのフィルターへ共通適用し、成功スキャンで補正を解除。兄弟パス・オフライン状態・元キャッシュ保持をテスト |

## 実画面で確認した流れ

1. **フォルダ不在のホーム** — フォルダと復旧操作を確認。クラウドの場合の説明と、操作対象の読み上げを改善。
2. **フォルダ設定から再スキャン** — 修正前は無変更で何も起きず、修正後はスキャン開始・24件の読込完了を確認。
3. **一覧と検索** — 2,615件の実プラグイン一覧を確認。修正版の合成セットでは `⌘2` → `⌘F` → `24` で1件に絞り込み。検索欄のフォーカスと件数は一致。
4. **サンプル検索から復帰** — 検索結果なしの状態で解除操作を確認し、8件のサンプル一覧に復帰。試聴やLive起動は行っていない。
5. **フォルダが消えた後の回復** — 合成フォルダを一時的に移動して旧一覧の保持を確認。「今すぐ開ける」の過大表示を修正し、フォルダの復帰後には再び利用可能として扱う。

`swift build` 成功。最終の `swift test --skip-build` は **1,009件、失敗0、条件付きスキップ11件**。追加・変更した回帰テストは先行する `swift test` でビルド済み。追加警告なし、`git diff --check` 成功。

- 新規回帰は18件。サンプル5件とプラグインの回帰は修正前に失敗を確認。その他は実ファイル変更・処理待機を使って問題の条件を検証した。
- 全体実行の途中、未変更の画像キャッシュ試験4件が一度失敗した。失敗はメモリ上の画像保持を期待する箇所で、ディスクへの保存・読込みは成功。当時OSのメモリ圧力が高く、NSCacheの任意退避の影響が考えられるが、退避イベントは未計測。コードや期待値を緩めず、関連22件の再実行と最終全体実行の両方で成功した。
- 修正版の画面で、合成ルート消失後の旧24件保持と利用可能0/24、復帰後の利用可能24/24を確認。復旧ボタンの対象パスもアクセシビリティツリーで確認した。

- 画面証拠と詳細なローカル検証記録は `macos/build/audit-2026-10-25/` に保存（配布物・Git管理の対象外）。
- 検証用Debugビルドで24セットの初回読込は約1.1秒、8音声の一覧走査はログ上2ms。小規模な動作確認値であり、大規模ライブラリの速度や修正前後の比較値ではない。
- キャンセルは処理境界で確認する。実行中のOSのファイル操作やソート自体を強制中断する保証はない。
- 今回の端末での確認範囲はApple Silicon / macOS 27.0.1。Intel、macOS 14、接続解除した実NAS、VoiceOver全操作、実際の音声再生は未検証。
